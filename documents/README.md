 Project Overview

The iGugulam Community Programme is an educational support initiative aimed at helping learners through homework assistance, tutoring, mentorship and access to educational resources.

Our group worked on developing a website to support the programme and make educational information and activities easier to access and manage.

 Purpose of This Folder

This folder contains five Agile Portfolio of Evidence documents demonstrating how Agile principles were applied during the planning, development and management of the iGugulam website.

 Portfolio Documents

1. Agile Team Charter.pdf – Describes the team's objectives, responsibilities, communication methods, working agreements and Agile approach.

2. User Stories and Tasks.pdf – Presents user requirements and the development tasks associated with the website.

3. Product Backlog.pdf – Records the prioritised project activities and tasks tracked using Trello.

4. Sprint Backlog.pdf – Documents sprint activities, development tasks and progress during the project.

5. Agile Logbook.pdf – Records Agile activities, progress, challenges and reflections throughout the project.

 My Individual Contributions

My contributions to the iGugulam website included frontend development, particularly:

- Dashboard
- Announcements

I also participated in backend development activities using Java and Spring Boot, project planning, task tracking and collaboration through GitHub.

 Agile Tools and Technologies

 Personal Reflection

Working on the iGugulam project helped me develop my technical skills, teamwork, communication, problem-solving and understanding of Agile project management.

The portfolio documents include evidence of project activities and personal reflections on my learning and contributions.
