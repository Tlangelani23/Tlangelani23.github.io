Project: iGugulam Community Programme

 Project Overview

The iGugulam Community Programme is an educational support initiative aimed at helping learners through homework assistance, tutoring, mentorship and access to educational resources.

Our group worked on developing a website to support the programme and make educational information and activities easier to access and manage.

 Purpose of This Folder

This folder contains five Agile Portfolio of Evidence documents demonstrating how Agile principles were applied during the planning, development and management of the iGugulam website.

 Portfolio Documents

Agile Team Charter.pdf – Describes the team's objectives, responsibilities, communication methods, working agreements and Agile approach.

User Stories and Tasks.pdf – Presents user requirements and the development tasks associated with the website.

Product Backlog.pdf – Records the prioritised project activities and tasks tracked using Trello.

Sprint Backlog.pdf – Documents sprint activities, development tasks and progress during the project.

Agile Logbook.pdf – Records Agile activities, progress, challenges and reflections throughout the project.

 STAR Reflection on My Agile Project Experience

Situation

I was part of a group responsible for developing the iGugulam Community Programme website as part of our Agile project assessment. The project aimed to support an educational initiative by providing learners and programme administrators with access to useful information and online features.

Task

My responsibility was to contribute to the development of the website, particularly the Dashboard, Announcements, Homework and Manage Announcements pages. I also participated in backend development activities, project planning and team collaboration.

Action

I worked on frontend development using HTML, CSS and JavaScript. I also participated in backend activities using Java and Spring Boot. I used Trello to track tasks and monitor project progress, while GitHub helped our team manage code and collaborate. I communicated with team members and contributed to Agile project activities.

Result

I gained practical experience in frontend and backend development, teamwork, version control and Agile project management. I also improved my problem-solving and communication skills and gained a better understanding of how software development projects are planned and completed in a team.
